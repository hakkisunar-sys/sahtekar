# Sahtekar Kim?

Herkesin kendi telefonundan oynadığı kelime oyunu. Bir kişi oyunu kurar, diğerleri kodla ya da QR ile katılır.
Sahtekar kelimeyi bilmez; herkes sırayla kelimeyi çağrıştıran bir şey söyler, sonra telefonlardan oy verilir.

17 kategori × 100 kelime. Oynamak için: https://hakkisunar-sys.github.io/sahtekar/
